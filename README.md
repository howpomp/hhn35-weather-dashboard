# Central Florida Halloween Weather

Independent public event-night weather dashboard for Universal Orlando Resort, Magic Kingdom and SeaWorld Orlando during the 2026 Halloween season.

## Features

- Venue selector for HHN35, Mickey's Not-So-Scary Halloween Party and SeaWorld Howl-O-Scream
- Calendar-aware presentation: hourly timelines on configured event nights and compact daily forecasts on non-event dates
- NWS point forecasts, digital grid data and active alerts for each venue
- KORL, KMCO and KISM observations with age and failure states
- Headline excerpt from the latest NWS Melbourne Area Forecast Discussion
- Three-venue comparison and responsive mobile layout

## Data sources

Weather data comes from the National Weather Service API. Event dates are maintained in `config.js` and should be verified against official venue schedules.
